# English Interview Practice

## Open locally

Double-click `index.html` to open the practice tool in a browser. No backend, package installation, or network connection is required.

## Practice flow

1. Choose a STAR story or an interview question topic.
2. Select `1 minute` or `Full answer` mode.
3. Click `Start 10s prep` and organize the answer in your head.
4. Speak using the STAR cues or the answer-framework cues.
5. Mark your self-review and save the attempt.

The library includes five STAR stories and four general interview topics: strengths, weakness, career goals, and expectations for the next role.

Practice history is stored in the browser's local storage on this device. It is not uploaded anywhere.
